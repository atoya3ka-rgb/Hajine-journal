# はじねジャーナル
### 始まりは寝たままジャーナルノート

**Ver.1.6｜PWA対応ジャーナリングアプリ**

「今日は何を書こう？」

そんなことを考えなくても、寝たまま、思いついたことから書き始められるジャーナルノートです。

体調や天気、その日の予定、何気ない気持ちを、スマートフォンから自由に記録できます。

日付は自動で設定され、タイトルは無題のままでも大丈夫。

毎日たくさん書かなくても、ほんの一言だけでも。

自分のペースで一日を記録するための、小さなノートです。

---

## 主な機能

### 一日一枚のジャーナル
- 日付の自動設定と任意のタイトル
- 天気・体温・室温・体感の過ごしやすさを記録
- 薄い横罫線の自由記述ノート
- 基本10行、最大35行のノート設計
- 見出し、箇条書き、チェックボックス、インデント
- 赤文字・青文字、3色マーカー、赤い打ち消し線、仕切り線

### 記録を振り返る
- 「書く」「めくる」「探す」「設定」の4タブ構成
- 保存したジャーナルをページごとに閲覧
- 日付やキーワードから過去の記録を検索
- 過去の日付のジャーナルも編集可能

### 保存・書き出し
- 端末内への自動保存
- 手動保存と編集の取り消し
- 一日分のジャーナルをPNG画像として保存
- JSON形式で全データをエクスポート・インポート

### 表示設定
- 白ページモード／ダークモード
- 文字サイズの倍率調整（80〜140％）
- スマートフォンでの利用を想定したPWA対応

## 使い方

1. アプリを開き、「書く」タブで今日のジャーナルを作成します。
2. 必要に応じて天気や体調を記録します。
3. 自由記述欄に、その日のことを書き込みます。
4. ツールバーから文字装飾やチェックボックスなどを追加できます。
5. 内容は自動保存され、あとから「めくる」「探す」で振り返れます。

### ホーム画面への追加

iPhoneではSafariで公開URLを開き、共有メニューから「ホーム画面に追加」を選択すると、アプリのように起動できます。

---

## データの取り扱い

ジャーナルの記録は、ブラウザのIndexedDBを利用して端末内に保存します。

アカウント登録は不要です。

端末やブラウザのデータ削除、機種変更などによって記録を失う可能性があるため、設定画面から定期的にJSONバックアップを書き出してください。

異なるブラウザやホーム画面アプリ間で、記録が自動的に同期されるわけではありません。

インポート時には、同じ日付の既存データが上書きされます。
